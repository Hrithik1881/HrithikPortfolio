## Run locally
1. Extract this ZIP to a folder.
2. Open that folder in Antigravity.
3. Open its terminal and run `npm install`.
4. Run `npm run dev` and open the local URL shown in the terminal.
5. Use Antigravity to inspect and refine the code, then run `npm run build` to verify.
